# Network Scanner

A simple Python-based tool that scans a target IP or domain using Nmap and displays open ports (1–1024) along with detected services.

## Features
* Scans IP or domain targets
* Shows only open ports
* Displays service information

## Example
Host: 127.0.0.1
| Port | State | Service       |
|------|-------|---------------|
| 135  | open  | msrpc         |
| 445  | open  | microsoft-ds  |
